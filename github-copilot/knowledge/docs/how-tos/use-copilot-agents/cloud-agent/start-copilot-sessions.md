# Starting GitHub Copilot sessions

> Source: https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/start-copilot-sessions
> Snapshot: github/docs @ 02c25d1 (2026-10-23)

_Choose your preferred way to start Copilot cloud agent sessions._

You can start Copilot cloud agent from several clients. Choose the one that fits your workflow:

* [GitHub](use-cloud-agent-on-github.md) — issues, agents tab, dashboard, Copilot Chat, new repositories, and failing GitHub Actions runs
* [GitHub Mobile](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-on-mobile)
* [IDEs](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-in-your-ide) — Visual Studio Code, JetBrains, Eclipse, and Visual Studio 2026
* [REST API](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-via-the-api)
* [GitHub CLI](use-cloud-agent-from-cli.md)
* [GitHub MCP Server](use-cloud-agent-with-mcp.md)
* [Jira](https://docs.github.com/en/copilot/how-tos/copilot-integrations/integrate-cloud-agent-with-jira)
* [Slack](https://docs.github.com/en/copilot/how-tos/copilot-integrations/integrate-cloud-agent-with-slack)
* [Microsoft Teams](https://docs.github.com/en/copilot/how-tos/copilot-integrations/integrate-cloud-agent-with-teams)
* [Azure Boards](https://docs.github.com/en/copilot/how-tos/copilot-integrations/integrate-cloud-agent-with-azure-boards)
* [Linear](https://docs.github.com/en/copilot/how-tos/copilot-integrations/integrate-cloud-agent-with-linear)
* [Raycast](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-from-raycast)

You can also start sessions automatically, on a schedule or in response to events such as an issue being opened, by setting up an automation. See [AUTOTITLE](create-automations.md).

Copilot will start working on the task in the background. Some entry points open a pull request automatically. In other cases, you can prompt Copilot to open a pull request, or create a pull request when Copilot finishes work, from the session logs.

For more information, see [AUTOTITLE](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github).
