# 07. Plans and AI credits (affects attendees)

Source: https://github.com/features/copilot/plans (fetched 2026-10-22)

| Plan | Price/mo | Credits | Notable |
|---|---|---|---|
| Free | $0 | Limited (50 chat/agent requests), 2,000 completions/mo | CLI, Copilot app, agent mode, MCP, custom instructions & agents. **No** cloud agent, Copilot code review, app modernization. Can't buy extra credits. |
| Pro | $10 | $15 total ($10 base + $5 flex) | Cloud agent, code review, third-party agents (Claude Code, Codex), model choice |
| Pro+ | $39 | $70 | Premium models incl. Opus, audit logs |
| Max | $100 | $200 | Priority access to new models/features |

- 1 AI credit = US$0.01. Chat, agent mode, CLI, Spaces, Spark use credits. Completions and next edit suggestions don't (unlimited on paid).
- Ways to stretch: lighter models, budgets (US$10 = 1,000 credits), alerts at 75/90/100%. In the app, `/chronicle cost tips`.
- Real-world app/CLI workshops require a paid or Student plan; First Steps works on Free but uses lots of credits.
