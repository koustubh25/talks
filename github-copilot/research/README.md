## Quick facts

**The event (Meetup):**
- **When:** Monday 16 Nov 2026, 5:30–7:30 pm AEDT (2 hours)
- **Where:** PwC, 2 Riverside Quay, Southbank, Melbourne
- **Who:** Azure Builders Melbourne; organizers Venura A. and Santhoshkumar A.; sponsored by Microsoft
- **Format:** "a mix of talks and hands-on time"; agenda and speakers not yet published
- **Focus:** GitHub Copilot in day-to-day work, in the Copilot app and the CLI

**The reference program (dev-days.github.com):**
- Theme: the **GitHub Copilot app** first, **Copilot CLI** second, Copilot SDK optional
- Official agenda shape: ~30 min talk + ~60 min hands-on lab
- Workshops burn a lot of AI credits on Copilot Free

## Caveats

- No agenda or talk lengths are published for Melbourne yet.
- Some reference workshop pages state totals that don't match the sum of their parts.
