# 03. Official sessions, slide decks, and agendas

## Source: github/dev-days/content (Sep–Oct 2026)

### Sample agenda (~2–3 hrs)

| # | Item | Type | Time |
|---|---|---|---|
| 01 | GitHub Copilot app | Session | 30–45 min (official deck) |
| 02 | Hands-on Lab | Lab | 60 min |

Organizers can adapt the format. Guidance: sessions introduce concepts, labs give practice, prefer **one lab per event**.

### Option 1 (recommended): GitHub Copilot app

**Session: "GitHub Copilot app"** — ~30 min, Beginner
- Slides (EN): https://github.com/github/dev-days/releases/download/2026-07-30/copilot-app-english.pptx
- Also ES / PT / ZH / KO / JA decks (same release, `copilot-app-<language>.pptx`)
- Recorded talk (EN): https://www.youtube.com/live/SsFU0w3KrI4
- Other languages: ES https://www.youtube.com/live/PTBDlAa0_aM · PT https://www.youtube.com/watch?v=O5ALS9rvTg8 · KO https://www.youtube.com/live/4ea0lmGXJiA · ZH https://www.bilibili.com/video/BV1T93v6VEca · JA https://www.youtube.com/watch?v=-ZBf4wpLZKg

Labs: "First Steps with the GitHub Copilot app" (Beginner) or "Real-world Development with the GitHub Copilot app" (Intermediate). See [04](04-workshops.md).

### Option 2: GitHub Copilot CLI

**Session: "GitHub Copilot CLI"** — ~30 min, Beginner. Terminal and command-line workflows.
- Slides: https://github.com/github/dev-days/releases/download/2026-07-30/copilot-CLI.pptx
- Framing used: "an autonomous coding agent that can plan complex tasks, run multistep workflows, edit files, run tests, and iterate until the job is done."

Labs: Tailspin Toys CLI (~2 hr, Intermediate) or Mona Mayhem (~1 hr).

### Attendee prerequisites (official)

- Copilot Free at minimum: https://aka.ms/get-github-copilot-devdays
- Copilot app: https://gh.io/dev-days/app
- Copilot CLI: https://docs.github.com/en/copilot/how-tos/copilot-cli/set-up-copilot-cli/install-copilot-cli
- Laptop
- Organizers should watch credit usage before/during the event
